[h1]STS2 Mod Translator[/h1]
Translate the text of [b]other mods[/b] into [b]any language[/b] — right inside the game, without rebuilding them.

[i]A utility/tool mod. It reads the localized text of your installed mods and lets you supply your own translations, injected back into the game at runtime — cards, relics, powers, characters and more, even for mods that don't ship your language.[/i]

[h2]🎮 Just want to play in your language?[/h2]
You don't need to translate anything yourself. If someone already made a translation pack for a mod:
[list]
[*]Subscribe to that [b]translation pack[/b] on the Workshop [b]and[/b] to this mod (Mod Translator). The pack lists this mod as required, so subscribing to it normally offers this one too.
[*]Launch the game in your language — the text applies automatically. No setup, no editing, no load-order to worry about.
[*][b]Finding packs:[/b] search the Workshop for the mod's name plus [i]Translation[/i] / [i]번역[/i] / [i]翻訳[/i] / [i]汉化[/i], or check the original mod's Workshop page for a linked translation.
[/list]
Everything below is for people who want to [b]create[/b] a translation.

[hr][/hr]

[h2]✍️ Create a translation — how to use[/h2]
[olist]
[*]Enable this mod and launch the game in the language you want to translate into.
[*]Open [b]Main Menu ▸ Mod Translator[/b] (it sits next to Settings).
[*]Drill down: pick a [b]mod[/b] ▸ a [b]language[/b] ▸ a [b]file[/b].
[*]Translate in the built-in editor, or [b]Upload[/b] a JSON file, or [b]Open Folder[/b] to edit externally.
[*]Press [b]Save[/b] — it validates and applies instantly. No restart needed.
[/olist]

[h2]In-game editor[/h2]
[list]
[*][b]Side-by-side panes[/b] — original text (read-only) on the left, your translation on the right.
[*][b]Reference dropdown[/b] — switch the left pane to any language the mod ships (compare against the existing Chinese/English), or [b]pack: <lang>[/b] to read an installed pack while you work.
[*][b]Line numbers[/b] and JSON validation on save.
[*][b]Empty-entry navigator[/b] — a live blank count plus a [b]Next empty ▼[/b] button that jumps to the next untranslated line. Each file also shows an [i]◦ N empty[/i] tag.
[*][b]Upload[/b] a file, or [b]Open Folder[/b] / [b]Reload[/b] for an external workflow.
[/list]

[h2]Machine-translate a first draft (DeepL)[/h2]
Don't want to start from a blank template? Fill empty entries automatically with [b]DeepL[/b], then review and Save — it only ever fills [b]blank[/b] entries, so your own work is never overwritten.
[list]
[*]Paste your own [b]DeepL API key[/b] once (the free tier's 500,000 chars/month is plenty) via the [b]DeepL key…[/b] button. The key is stored [b]locally only[/b] and never ends up in exported packs.
[*][b]Auto-fill[/b] drafts the current file; [b]Auto-fill all[/b] does every file at once. The buttons stay disabled until a key is set.
[*][b]Placeholders and markup are protected[/b] — variables ([i]{Damage}[/i]), icon/image tags and highlight tags ([i][gold]…[/gold][/i]) are preserved so machine translation can't break them.
[*][b]BaseLib mods supported[/b] — shorthand like [i]!Damage![/i] or [i]*keyword*[/i] (used by FGO-based mods) is converted like the original, so it renders as numbers/highlights instead of raw [i]!Var![/i] text.
[/list]
It's a [b]draft[/b] for every DeepL-supported language — game-specific terms still deserve a quick human pass.

[h2]Share translations as a standalone mod[/h2]
Turn your work into its own mod — just like other mods reference [b]baselib[/b], a [i]translation mod[/i] references this one. Others install your pack (plus this mod) and the text applies automatically, no editing.
[list]
[*]Enter your name in [b]Author[/b], pick a mod, press [b]Install as mod[/b] — it builds a ready-to-ship [i]<ModName>_Translation[/i] mod in your local [i]<STS2>/mods/[/i] folder (manifest + your translations for every language you worked on). No DLL or coding needed.
[*][b]Bundle many mods into one pack[/b] — on the mod list press [b]Bundle pack…[/b], tick several translated mods, name it, and [b]Install pack to mods[/b] to ship them all as a single Workshop item instead of one per mod.
[*][b]Update without re-picking[/b] — an [b]Existing packs ▾[/b] menu re-loads a pack you already deployed (re-ticks its mods and bumps the version); a [b]Reset[/b] button clears everything to start a fresh pack.
[*][b]Publish to the Workshop[/b] like any normal mod — subscribers who also have [b]Mod Translator[/b] get your text. Or just zip the folder to hand it over. Restart the game to test it first.
[*]Installed packs are detected at boot and applied last: your in-editor edits beat a pack, a pack beats the original. The mod list shows each pack's per-language coverage (e.g. [i]pack: kor 87%[/i]).
[/list]

[h2]Updating a translation mod[/h2]
When the original mod updates (new cards, reworded text), staying in sync is easy: relaunch and new keys are [b]detected automatically[/b] as empty entries — your existing work is untouched and removed lines fall back to the original. Translate only the gaps, press [b]Install as mod[/b] again ([b]Update installed mod[/b] pre-fills the next version), and re-upload to the same Workshop item.

[h2]Translation tips[/h2]
Keep placeholders ([b]!D![/b], [b]!B![/b], [b]!Crit![/b]) and markup ([b]*[/b]keyword, leading [b]#[/b], [b]/+[/b], [b][color][/b] tags) intact — change only the human-readable text. Leave a value [b]empty[/b] to keep the original (English) text for that entry.

[h2]Scope & compatibility[/h2]
[list]
[*]Works with mods that ship a standard localization folder — most well-made content mods (e.g. custom characters).
[*]Mods that hardcode text, register it at runtime, or load their own localization outside the game's system are listed as [i]unsupported[/i] — tap the entry to see each mod and the exact reason.
[*]Even mods that ship no English ([i]eng[/i]) table work — the richest language they do ship becomes the reference to translate from.
[*][b]No load-order requirement[/b] — translations are always applied last automatically.
[/list]
