[h1]STS2 Mod Translator[/h1]
Translate the text of [b]other mods[/b] into [b]any language[/b] — right inside the game, without rebuilding them.

[i]A utility/tool mod. It reads the localized text of your installed mods and lets you supply your own translations, injected back into the game at runtime — cards, relics, powers, characters and more, even for mods that don't ship your language.[/i]

[hr][/hr]

[h2]🌐 Quick start · 빠른 시작[/h2]
[b]EN[/b]  🎮 Play a mod in your language → just subscribe to a translation pack that requires this mod.  ✍️ Translate one yourself → Main Menu ▸ Mod Translator, pick a mod & language, fill the text (DeepL can draft it).
[b]한국어[/b]  🎮 모드를 내 언어로 플레이 → 이 모드를 필요로 하는 번역팩을 구독하면 끝.  ✍️ 직접 번역 → 메인 메뉴 ▸ 모드 번역기(Mod Translator)에서 모드·언어를 고른 뒤 텍스트 입력 (DeepL 자동 초안 지원).

[h2]🎮 Just want to play in your language?[/h2]
You don't need to translate anything yourself. If someone already made a translation pack for a mod:
[list]
[*]Subscribe to that [b]translation pack[/b] on the Workshop [b]and[/b] to this mod (Mod Translator). The pack lists this mod as required, so subscribing to it normally offers this one too.
[*]Launch the game in your language — the text applies automatically. No setup, no editing, no load-order to worry about.
[*][b]Finding packs:[/b] search the Workshop for the mod's name plus [i]Translation[/i] / [i]번역[/i] / [i]翻訳[/i] / [i]汉化[/i], or check the original mod's Workshop page for a linked translation.
[/list]
Everything below is for people who want to [b]create[/b] a translation.

[hr][/hr]

[h2]✍️ Create a translation — how to use[/h2]
[olist]
[*]Enable this mod and launch the game in the language you want to translate into.
[*]Open [b]Main Menu ▸ Mod Translator[/b] (it sits next to Settings) — or, mid-run, [b]Pause ▸ Mod Translator[/b].
[*]Drill down: pick a [b]mod[/b] ▸ a [b]language[/b] ▸ a [b]file[/b].
[*]Translate in the built-in editor, or [b]Upload[/b] a JSON file, or [b]Open Folder[/b] to edit externally.
[*]Press [b]Save[/b] — it validates and applies instantly. No restart needed.
[/olist]

[h2]In-game editor[/h2]
[list]
[*][b]Side-by-side panes[/b] — original text (read-only) on the left, your translation on the right.
[*][b]Reference dropdown[/b] — switch the left pane to any language the mod ships (compare against the existing Chinese/English), or [b]pack: <lang>[/b] to read an installed pack while you work.
[*][b]The reference follows you[/b] — move the caret and the left pane scrolls to that entry, highlights it, and names the key in the header. It matches by key, not line number.
[*][b]Find[/b] — saw an awkward line while playing? Type it (or one distinctive word) in the [b]Find[/b] box and jump straight to that entry. It searches the [b]original[/b], your [b]translation[/b] and the [b]key[/b], so it works even on entries you haven't translated yet, and color tags / [i]!D![/i] placeholders are ignored — you can paste what the game showed you. Every occurrence is [b]highlighted in both panes[/b] as you type, and the jump selects the one you're on. Enter (or [b]Ctrl+F[/b] from the editor) cycles the matches.
[*][b]Line numbers[/b] and JSON validation on save.
[*][b]Empty-entry navigator[/b] — a live blank count plus a [b]Next empty ▼[/b] button that jumps to the next untranslated line. Each file also shows an [i]◦ N empty[/i] tag.
[*][b]Upload[/b] a file, or [b]Open Folder[/b] / [b]Reload[/b] for an external workflow.
[/list]

[h2]Fix a line without leaving your run[/h2]
The editor opens from the [b]pause menu[/b] too — see an awkward line mid-fight, pause, fix it, resume. Save applies to the live text instantly, and the run is untouched. Game hotkeys are suspended while the panel is open, so typing can't leak into the game as a card play. [b]Esc[/b] closes just the panel and leaves the pause menu up — press it again to resume the run.

[h2]Machine-translate a first draft (DeepL)[/h2]
Don't start from a blank template — [b]DeepL[/b] fills the [b]empty[/b] entries and never overwrites your work. Paste your own API key once (the free tier's 500,000 chars/month is plenty): [b]Auto-fill[/b] drafts the open file, [b]Auto-fill all[/b] does every file at once. Placeholders, markup and BaseLib shorthand are protected, so machine translation can't break them. It's a draft — game-specific terms still deserve a human pass.

[h2]🤖 Or hand it to an AI agent[/h2]
An [b]AI coding agent[/b] (Claude Code and similar) reads a whole file at once, so terminology stays consistent — and it handles what DeepL must skip: some text hides translatable words [i]inside[/i] a placeholder ([i]{Amount:plural:a card|{} cards}[/i]), which machine translation has to leave in English.
[list]
[*][b]Nothing to explain[/b] — the folder already holds the rules and your language's official in-game terms, taken from the game itself. No path to paste, no format to describe; agents pick them up on their own, and the files are rebuilt at every launch.
[/list]
Press [b]Translate with AI…[/b] on the mod list for the three steps, then [b]Reload[/b]. Bring your own agent — this mod only prepares the folder.

[h2]Share translations as a standalone mod[/h2]
Turn your work into its own mod — just like other mods reference [b]baselib[/b], a [i]translation mod[/i] references this one. Press [b]Install as mod[/b], or [b]Bundle pack…[/b] to ship several mods' translations as a single Workshop item, and it builds a ready-to-publish folder — no DLL, no coding. Subscribers who also have Mod Translator get your text automatically, with no load order to worry about.

[h2]Scope & compatibility[/h2]
[list]
[*]Works with mods that ship a standard localization folder — most well-made content mods (e.g. custom characters).
[*]Mods that hardcode text, register it at runtime, or load their own localization outside the game's system are listed as [i]unsupported[/i] — tap the entry to see each mod and the exact reason.
[*]Even mods that ship no English ([i]eng[/i]) table work — the richest language they do ship becomes the reference to translate from.
[*][b]No load-order requirement[/b] — translations are always applied last automatically.
[/list]
